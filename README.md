# Mokshaa Luxury Wellness Spa — Client Demo

A responsive six-page React + TypeScript + Vite + Tailwind CSS website concept for Mokshaa Luxury Wellness Spa, Indore.

## Pages
- `/` — Home
- `/about` — About Mokshaa
- `/treatments` — Treatments catalogue
- `/packages` — Experience concepts
- `/gallery` — Image gallery with lightbox
- `/contact` — Contact, location, FAQs and WhatsApp enquiry

## Run locally
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
npm run preview
```

## Before presenting or publishing
1. Confirm the official WhatsApp booking number. WhatsApp links currently open with a pre-filled message but no recipient number, to avoid using an unverified number.
2. Confirm the full business address, phone number and opening hours.
3. Confirm treatment names, descriptions, durations, pricing and current offers with the spa owner. Menu entries were transcribed provisionally from the supplied Instagram screenshot.
4. Package names, durations and inclusions are illustrative demo concepts, not confirmed offers.
5. Replace curated Unsplash spa imagery with approved, original Mokshaa photographs before launch. Gallery and hero imagery are visual placeholders and must not be represented as photographs of the actual premises.
6. Add genuine, approved customer testimonials before publishing. No fabricated reviews are included.
7. The demo uses the existing Instagram profile link: https://www.instagram.com/mokshaaspa_01/

## Design direction
Champagne gold, warm ivory, taupe and deep espresso; Cormorant Garamond display typography; DM Sans body typography; editorial photography; responsive navigation; WhatsApp enquiry CTAs.
